How a toy works

Your browser talks to a tiny Worker

The page never sees an API key. A Cloudflare Worker holds it as a secret, checks the Turnstile token, and counts your usage.

The Worker calls AIVAX

Each call is a plain HTTPS request to the public AIVAX API. The Worker forwards the result, plus timing, request ID and usage.

You see the real numbers

The session panel lists every call, its latency and processing units, and keeps a running cost estimate so you know what the same work would cost you.
